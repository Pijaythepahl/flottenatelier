# Miniaturen

Erstellt mit dem integrierten Imagegen-Werkzeug. Projektdateien: `dist/assets/*.png`. Generische isometrische Illustrationen ohne reale Klassenbindung; keine Aussage über tatsächliche Ausrüstung. Die Frigatte verwendet denselben Stil mit explizitem Helideck, Mast und Brücke.
